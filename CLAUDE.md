# Instrucciones del proyecto

## Idioma
- Responder SIEMPRE en español (Panamá), incluidas las explicaciones, resúmenes y preguntas.
- Mensajes de commit, descripciones de PR, comentarios de código y textos de la interfaz: en español.

## Proyecto
- Command Center de GG: agencia ARRIVE, eventos/venues en Panamá y portafolio de proyectos.
- El agente se llama **Bart**. La única sección que dice "OpenClaw" es "OpenClaw Master Orchestrator"
  (conectada al OpenClaw del Mac mediante `bridge/bart-bridge.mjs`).
- Antes de entregar cambios: `npm run lint`, `npm test` y `npm run build` deben pasar.
