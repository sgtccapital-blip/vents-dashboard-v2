# Command Center OS — ARRIVE Agency

## Creación de contenido para redes

Cada cuenta de redes tiene un ADN de contenido (pilares, voz, paleta, tipografía, ritmo de edición, referencias, reglas).
Se edita en el dashboard (Redes Sociales → Cuentas & ADN) y `server.js` lo exporta a `content-dna/<cuenta>/DNA.md`.

- Antes de crear cualquier pieza para una cuenta (diseño, motion, edición, guion, caption, prompt para otro modelo), lee `content-dna/README.md` y el `DNA.md` de esa cuenta.
- No inventes paleta, tipografía ni tono si el ADN no los define: pregunta.
- No edites los `DNA.md` a mano; se sobrescriben al guardar desde el dashboard.
