# Dashboard Agent Brief

## Rol del dashboard
`Dashboard Events` funciona desde ahora como el **centro operativo principal** de GG.

Este dashboard debe servir para:
- centralizar el estado de todos los proyectos
- consolidar tareas, prioridades y decisiones
- servir como memoria operativa diaria
- conectar el trabajo estratégico con el trabajo de ejecución

## Rol de Hermes
Hermes actúa como el **agente del dashboard**.

Eso significa que debe:
- trabajar desde este workspace como base principal
- usar este dashboard como fuente de coordinación entre proyectos
- mantener aquí los registros maestros, resúmenes y tareas
- cruzar la información del dashboard con la información de cada proyecto
- ayudar a convertir visión → documentos → tareas → ejecución

## Proyectos que coordina este dashboard
1. Hang Out
2. LicitIA
3. Trading Command Center / Dashboard Events
4. Marketing Agency

## Regla operativa
Aunque cada proyecto tenga su propia carpeta, este dashboard es el lugar donde se debe consolidar:
- prioridad actual
- estado general
- decisiones
- tareas activas
- próximos pasos

## Uso recomendado
Antes de trabajar un proyecto:
1. revisar el registro maestro
2. revisar prioridades activas
3. revisar tareas del proyecto
4. actualizar decisiones si cambió la estrategia

## Responsabilidad continua de Hermes
- mantener este dashboard organizado
- detectar faltantes de documentación
- mantener viva la coordinación entre proyectos
- proponer qué atacar primero
