# Portfolio Task Plan

## Objetivo
Organizar los cuatro proyectos principales de GG en planes de trabajo accionables, coordinados desde el Command Center.

## Proyectos
1. Hang Out
2. LicitIA
3. Trading Command Center
4. Marketing Agency

## Regla de ejecución
- primero claridad estratégica
- luego estructura documental
- luego sistema de tareas
- luego validación operativa
- luego ejecución técnica/comercial

## Prioridad actual
1. Hang Out
2. LicitIA
3. Trading Command Center
4. Marketing Agency

## Entregables mínimos por proyecto
- Executive Summary
- Business Plan
- Marketing Plan
- Task System
- Task Plan detallado
- Roadmap posterior

## Resultado esperado
Cada proyecto debe tener:
- dirección clara
- tareas agrupadas por bloque
- prioridades definidas
- siguiente movimiento inequívoco
