marketing, automatización y activos comerciales, dirigida a constructoras, consultoras y startups

## Cómo se trabaja
1. Social media: calendario → diseño → copy → aprobación → publicación.
2. Paid ads: audiencia → creativo → lanzamiento → optimización semanal.
3. Web: wireframe → diseño → desarrollo → QA → deploy.
4. SEO: keyword research → redacción → publicación → link building.
5. Automatización IA: diagnóstico → flujo → implementación → testing → entrega.
6. Branding: brief → propuestas → iteración → entregables finales.
